# 📤 الملفات المرفوعة

هذا المجلد مخصص للملفات التي يتم رفعها من قِبل المستخدم (مستندات، صور، جداول، ملفات PDF... إلخ).

## التنظيم المقترح
```
الملفات-المرفوعة/
├── مستندات/     # Word / PDF / نصوص
├── صور/         # صور ولقطات شاشة
├── جداول/       # Excel / CSV
└── أخرى/        # أي نوع آخر
```

## طريقة التسمية المقترحة
```
YYYY-MM-DD_اسم-الملف.الامتداد
```
مثال: `2026-09-07_عقد-التوريد.pdf`

## ملاحظات
- تجنب المسافات في أسماء الملفات واستخدم الشرطة `-` بدلًا منها.
- لا تُرفع الملفات الكبيرة جدًا أو الملفات التي تحتوي على بيانات حساسة.
- الملفات غير المرغوب بها تُنقل إلى مجلد `سلة-المهملات` بدل حذفها مباشرة.
