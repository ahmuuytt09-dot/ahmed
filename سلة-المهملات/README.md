# 🗑️ سلة المهملات

مجلد مؤقت للملفات المحذوفة أو التي لم تعد مستخدمة، قبل حذفها نهائيًا.

## طريقة العمل
1. بدل حذف أي ملف نهائيًا، انقله إلى هذا المجلد.
2. أضف تاريخ النقل إلى اسم الملف:
   ```
   YYYY-MM-DD_اسم-الملف-الأصلي.الامتداد
   ```
3. تُراجَع محتويات المجلد دوريًا (مثلًا كل شهر) وتُحذف الملفات التي مضى عليها أكثر من 30 يومًا.
