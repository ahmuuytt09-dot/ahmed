# 📆 التقارير الشهرية

هذا المجلد مخصص لحفظ التقارير الشهرية.

## طريقة التسمية
```
YYYY-MM.md
```
مثال: `2026-09.md` (تقرير شهر سبتمبر 2026)

## قالب التقرير الشهري

```markdown
# التقرير الشهري: سبتمبر 2026

## 📊 الملخص التنفيذي
-

## ✅ الإنجازات الرئيسية
-

## 📈 المؤشرات الشهرية
| المؤشر | المستهدف | المحقق | نسبة الإنجاز |
|--------|----------|--------|--------------|
|        |          |        |              |

## ⚠️ التحديات والمخاطر
-

## 💡 التوصيات
-

## 🎯 أهداف الشهر القادم
-
```

## ملاحظات
- يُبنى التقرير الشهري على تجميع التقارير الأسبوعية من مجلد `التقارير-الاسبوعية`.
