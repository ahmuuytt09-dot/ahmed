# 🗓️ التقارير الأسبوعية

هذا المجلد مخصص لحفظ التقارير الأسبوعية.

## طريقة التسمية
```
YYYY-Wنن.md
```
مثال: `2026-W36.md` (الأسبوع السادس والثلاثون من عام 2026)

## قالب التقرير الأسبوعي

```markdown
# التقرير الأسبوعي: 2026-W36
**من:** 2026-09-01 &nbsp;&nbsp; **إلى:** 2026-09-07

## 📊 ملخص الأسبوع
-

## ✅ أبرز الإنجازات
-

## 📉 المؤشرات والأرقام
| المؤشر | القيمة | مقارنة بالأسبوع السابق |
|--------|--------|------------------------|
|        |        |                        |

## ⚠️ التحديات
-

## 🎯 خطة الأسبوع القادم
-
```
