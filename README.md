# ahmed

مستودع لتنظيم التقارير والملفات.

## 📁 هيكل المجلدات

| # | المجلد | الوصف |
|---|--------|-------|
| 1 | [التقارير-اليومية](./التقارير-اليومية/) | التقارير اليومية — ملف لكل يوم بصيغة `YYYY-MM-DD.md` |
| 2 | [التقارير-الاسبوعية](./التقارير-الاسبوعية/) | التقارير الأسبوعية — ملف لكل أسبوع بصيغة `YYYY-Wنن.md` |
| 3 | [التقارير-الشهرية](./التقارير-الشهرية/) | التقارير الشهرية — ملف لكل شهر بصيغة `YYYY-MM.md` |
| 4 | [الملفات-المرفوعة](./الملفات-المرفوعة/) | الملفات التي يرفعها المستخدم (مستندات، صور، جداول، أخرى) |
| 5 | [سلة-المهملات](./سلة-المهملات/) | الملفات المحذوفة مؤقتًا قبل الحذف النهائي |

```
ahmed/
├── التقارير-اليومية/
├── التقارير-الاسبوعية/
├── التقارير-الشهرية/
├── الملفات-المرفوعة/
│   ├── مستندات/

│   ├── جداول/
│   └── أخرى/
└── سلة-المهملات/
```

## 📝 قواعد عامة
- كل مجلد يحتوي على ملف `README.md` يشرح طريقة التسمية ويوفّر قالبًا جاهزًا.
- استخدم الشرطة `-` بدل المسافات في أسماء الملفات.
- لا تحذف الملفات مباشرة — انقلها إلى `سلة-المهملات` أولًا.
- التقارير الأسبوعية تُبنى من اليومية، والشهرية تُبنى من الأسبوعية.
