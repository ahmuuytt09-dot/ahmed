# 📅 التقارير اليومية

هذا المجلد مخصص لحفظ التقارير اليومية.

## طريقة التسمية
```
YYYY-MM-DD.md
```
مثال: `2026-09-07.md`

## قالب التقرير اليومي

```markdown
# تقرير يوم: 2026-09-07

## ✅ المهام المنجزة
-

## 🔄 المهام قيد التنفيذ
-

## ⚠️ المعوقات والملاحظات
-

## 📌 مهام الغد
-
```

## ملاحظات
- يُرجى إنشاء ملف واحد لكل يوم.
- الملفات القديمة التي لم تعد مطلوبة تُنقل إلى مجلد `سلة-المهملات`.
